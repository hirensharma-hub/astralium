## Testing Checklist

- Confirm the mod loads and the Astralium tab appears.
- Confirm every item and block has a texture and translation.
- Test ore generation in newly generated outer End chunks.
- Test Fortune, Silk Touch, smelting, blasting, and storage recipes.
- Test template duplication and every smithing recipe.
- Test V key rebinding and per-pickaxe mode persistence.
- Test wall, floor, and ceiling highlights.
- Confirm area mining is one block deep and protects block entities.
- Confirm every mined block consumes durability and stops when the tool breaks.
- Confirm no recursive area mining occurs.
- Confirm all momentum chains reset after about 2.5 seconds.
- Confirm sword momentum increases damage by percentage, not fixed points.
- Confirm axe combat momentum changes attack recovery, not axe damage.
- Confirm Voidbound preserves item NBT and does not rescue the player.
- Test void features only in a copied world.
- Confirm dedicated server startup has no client-only class loading crash.

## Fiverr Summary

Astralium is a polished Forge 1.20.1 portfolio mod demonstrating professional Java modding patterns: custom registries, End ore generation, data-driven recipes and loot, smithing progression, keybind networking, server-authoritative area mining, custom block highlighting, temporary combat/mining momentum, dropped-item void protection, armour set abilities, generated original textures, advancements, configuration, and documentation.
